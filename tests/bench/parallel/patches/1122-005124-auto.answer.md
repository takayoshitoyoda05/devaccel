`click.Path(extensions=[".csv", ".tsv"])` で、受け付ける拡張子を制限できるようにしました(大文字小文字は区別しません)。PR は https://github.com/takayoshitoyoda05/devaccel-large/pull/17 で、ラベルは `needs-human`(4 ファイル変更で L 規模のため)です。

決めた扱い:
- 先頭の `.` は省略できます。`.tar.gz` のような複数部分の拡張子も使えます。
- 存在しないパスにも適用するので、出力ファイルにも使えます。
- ディレクトリと `allow_dash` の `-` は検査しません。
- 空リスト・空文字・`"."` は `ValueError`、`".csv"` のような文字列そのものは `TypeError` にしました。

確かめていないこと:
- `to_info_dict` と shell 補完には反映していません(`executable` と同じ扱いです)。
- 実際の端末で `--help` は動かしていません。`--help` の文言は変えていません。
- PR 作成時の検査(`check.sh fast`)の結果は、出力が PR の URL だけだったので確認できていません。
