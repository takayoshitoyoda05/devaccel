`--report --total` で、月ごとの小計行と全体の合計行が出るようにしました。検査は通り、PR にしています。

PR: https://github.com/takayoshitoyoda05/devaccel-trial/pull/344 `[evidence-ok]`

決めた形式は次のとおりです。各月の末尾に `YYYY-MM<TAB>TOTAL<TAB>円`、最後に `TOTAL<TAB><TAB>円` を出します。列は既存の `--report` に合わせて 3 列、桁区切りなしです。

実際に動かして確かめたのは、`--report --total` と `--help`、`--memo` の絞り込み後の集計、空 CSV、一致なし、返金の合算です。

opus のレビュー指摘のうち、フォーマット崩れ、弱いテスト、`--memo` の README 記述の 3 点を直しました。`--category` と `--format csv` の併用テストも足しています。カテゴリ名が `TOTAL` のときに小計行と区別できない点は、既定出力と同じなので手を入れていません。

`--report --total --budget` の併用は動かしていません。予算の警告は集計値から作るので影響しない想定です。
