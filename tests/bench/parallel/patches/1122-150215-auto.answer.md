決めた扱い: `extensions=[".csv", ".tsv"]` のように指定します。大文字小文字は区別せず、先頭のドットは省略できます。`.tar.gz` のような複数部分の拡張子も使えます。存在しないパスにも検査をかけますが、ディレクトリと `allow_dash` の `-` は対象外で、未指定なら従来どおり何でも通ります。空リスト・空の拡張子・文字列単体の指定は `ValueError` か `TypeError` です。

確かめていないこと: 新しいエラー文言の翻訳、シェル補完での拡張子の絞り込み、実際のターミナルでの手動実行。テストは `scripts/check.sh fast` で通っています。CI と同じ full は PR 側の証拠作成で走ります。
