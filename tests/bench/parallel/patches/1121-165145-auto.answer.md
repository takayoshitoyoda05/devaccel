`--budget` は、月×カテゴリの集計が予算を超えた分を stderr に警告するだけの機能です。stdout の内容は変わらず、終了コードも 0 のままです。コードは変更していません(`src/kakeibo/core.py` と `src/kakeibo/__init__.py` を読みました)。

## 予算 JSON の形式

```json
{
  "default": {"food": 30000, "rent": 80000},
  "months": {
    "2026-11": {"food": 40000},
    "2026-12": {"transport": 5000}
  }
}
```

- `default` は全月に共通の予算です。`months` は特定の月だけの予算で、キーは `YYYY-MM` です。
- 月ごとの指定は **カテゴリ単位で default を上書き**します(`Budget.for_month`、`core.py:91`)。
  - 上の例の 2026-11 は food が 40000 に上がり、rent は default の 80000 のままです。
  - 2026-12 は transport が追加され、food と rent は default のままです。
  - `months` に書いていない月は default だけが使われます。
- `default` と `months` はどちらも省略できます。両方省略した `{}` は有効で、予算なしと同じ扱いです。
- 次の場合は `BudgetError` になり、stderr にメッセージを出して**終了コード 2** で終わります。
  - ファイルが読めない
  - JSON が不正
  - 最上位がオブジェクトでない
  - `months` がオブジェクトでない
  - 月キーが `YYYY-MM` でない(`2026-13` も不可)
  - 金額が 0 以上の整数でない(負数・小数・文字列・bool は不可)
- 予算ファイルは CSV より先に読むので、予算が不正なら CSV のエラーより先に終了します(`__init__.py:58-64`)。

## どの集計と比べているか

`monthly_totals(rows)` が作る **月別×カテゴリ別の合計**(`{"YYYY-MM": {category: yen}}`)と比べます。`--report` を付けた場合だけでなく、付けなくても必ずこの月別集計で比較します(`__init__.py:76`、`:105-110`)。

- 超過は `actual > limit` のときだけ警告します。ちょうど予算額なら警告しません。
- 予算にないカテゴリは警告の対象外です。
- 実績のない月やカテゴリには警告が出ません。
- 警告の形式は `警告: 2026-11 food 1,150円超過 (予算 1,000 / 実績 1,150)` で、stderr に出ます。出力は最後(通常の出力の後)です。

## --memo / --category との組み合わせ

- **`--memo`**: 絞り込み後の行で集計してから比較します(`__init__.py:71-76`)。そのため `--memo coffee` では、coffee を含む行の合計だけが予算と比べられます。全体の実績ではないので、実際の支出が予算を超えていても警告が出ないことがあります。この挙動は README とテスト(`tests/test_memo.py:66` の `test_memo_budget_uses_filtered_rows`)で明記されています。一致する行が 0 件のときは、警告も出ません。
- **`--category`**: 警告には**影響しません**。`--category` は既定出力の `totals_by_cat` だけを絞り込みます(`__init__.py:85-90`)。一方、予算チェックに渡す `totals` は絞り込み前の月別集計です。そのため `--category food` と付けても、他カテゴリ(rent など)の超過警告は出ます。表示しているカテゴリと警告の対象がずれる点は、意図された仕様かどうか確認が必要です。ドキュメントやテストには、`--category` と `--budget` の併用を扱った箇所が見当たりません。
- **`--report`**: 月別の表を stdout に出し、警告は stderr に出ます。`--report` では `--category` が無視されるので、警告もすべてのカテゴリが対象です。
