`--budget` の出力に予算に対する割合(%)が付くようになり、超過していなくても 90% 以上使っていれば「注意」が出ます。テスト・ruff・pyright はすべて通り、`e1f71d4` でコミットしました。

**出力例**
```
警告: 2026-11 food 1,000円超過 (予算 1,000 / 実績 2,000 / 200%)
注意: 2026-11 food 残り 100円 (予算 1,000 / 実績 900 / 90%)
```

**変更内容**
- `core.py` に、警告・注意の対象を探す処理と、その文言を作る処理を追加しました。今まで超過の検出に使っていた `find_overruns` は残してありますが、CLI ではもう使っていません。
- テスト: 既存の 2 件を新しい出力に合わせて直し、10 ケースの境界値テストなどを追加しました。境界値は 89.9%(出ない)/ 90% / 100% / 100.1% / 予算 0 / 実績がマイナス、の各パターンです。
- README と `--help` の説明も更新しました。

**仕様として決めたこと**(違えば調整します)
- **割合は小数点以下を切り捨て**ます。89.9% が「90%」と表示されて基準を満たしているように見えないようにするためです。ただしその分、1,001/1,000 のような僅かな超過は「警告 … 100%」と表示されます。
- **ちょうど予算どおり(100%)は「注意」**になります。以前は何も出さなかった部分です。
- **予算 0 のカテゴリは割合を出しません**。支出が 1 円以上あれば警告だけ出し、支出も 0 なら何も出しません。
- **一行の中では、超過していれば「◯円超過」、していなければ「残り ◯円」**と書き分けています。

なお、実際の CLI を手で実行して確認するのは、一時ファイルを作るコマンドが許可されなかったので行っていません。CLI の出力はテストの中で確認しています。
