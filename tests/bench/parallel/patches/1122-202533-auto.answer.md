`click.Path` に `extensions` 引数を足して PR にしました: https://github.com/takayoshitoyoda05/devaccel-large/pull/83

PR には「証拠を作成中」と出ています。base の `check.sh full` が終わるとラベルが付き、下書きが解除されます。マージは人が行います。

- **使い方**: `click.Path(extensions=["csv", "tsv"])` のように指定します。大文字小文字は区別せず、先頭のドットは付けても付けなくても同じです。`.tar.gz` のようなドットが複数ある拡張子も使えます。
- **検査しないもの**: 既存のディレクトリと、`allow_dash` で許可した `-` には拡張子の検査をしません。`exists=True` でファイルが無いときは、「存在しない」というエラーが先に出ます。
- **不正な引数**: 文字列そのものや文字列でない要素は `TypeError`、空のリストや空の要素は `ValueError` です。
- **既定値**: 指定しない場合の動きは変わりません。
- **付随して直したもの**: `to_info_dict()` に `extensions` を足しました。`CHANGES.md` と `docs/handling-files.md` にも追記しました。
- **テスト**: `tests/test_types/test_Path.py` に追加しました。`scripts/check.sh fast` は 2656 件が通っています。
- **実機確認**: `a.TSV` は通り、`a.txt` は `Path 'a.txt' must have one of the extensions: .csv, .tsv.` で終了コード 2 になりました。
