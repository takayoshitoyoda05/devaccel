`--report --total` で、月ごとの小計の行と最後の総合計の行が出るようにしました。テストは全63件通り、ruff と pyright もエラーなしです。コミットは `2f4aafb` です。

```
$ uv run kakeibo data/sample.csv --report --total
2026-11	rent	80000
2026-11	food	2000
2026-11	SUBTOTAL	82000
TOTAL		82000
```

指定がなかったので、出力の形は私が決めました。
- **小計の行:** 各月の最後に `YYYY-MM<TAB>SUBTOTAL<TAB>金額` を出します。
- **総合計の行:** `TOTAL<TAB><TAB>金額` の形にしました。全行を3列にそろえて、TSV として読み込みやすくするためです。
- **金額:** `--report` のほかの行に合わせて、桁区切りは付けていません。
- **一致する行がないとき:** `--memo` に一致する行がない場合や CSV が空の場合は、`TOTAL		0` だけを出します。`--report` なしのときと同じ動きです。

ほかに変えたもの:
- `src/kakeibo/__init__.py`: 出力の処理と `--total` のヘルプ文
- `README.md`: 「`--report` では合計行は出ない」という説明を書き直し、出力例を追加
- `tests/test_report_total.py`(新規): 月が複数ある場合、各行が3列になること、`--memo` と一緒に使った場合・一致なしの場合、CSV が空の場合、`--category` が無視されること、`--total` なしでは出力が変わらないこと、をテスト

なお、カテゴリ名がそのまま `SUBTOTAL` だと、小計の行と見分けがつきません。通常の表示の `TOTAL` 行にも同じ問題があります。
