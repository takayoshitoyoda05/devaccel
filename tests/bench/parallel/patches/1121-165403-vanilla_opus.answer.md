## 1. 予算 JSON の形式

```json
{
  "default": {"food": 30000, "rent": 80000},
  "months": {
    "2026-12": {"food": 50000}
  }
}
```

- **`default`**: 全部の月に使う、カテゴリごとの上限(円)。書かなければ `{}` になります。
- **`months`**: キーは `YYYY-MM`(01〜12 月のみ)。その月だけの上限です。書かなければ `{}` になります。
- **値のルール**: 0 以上の整数だけです。文字列、負の数、`true`/`false` はエラーになります。
- **エラーになる書き方**: 最上位がオブジェクトでない、`months` やその中身がオブジェクトでない、月の書式が違う(`2026-13`、改行付き、全角数字など)。
- **無視されるもの**: 上記以外の最上位キーは黙って無視されます。
- **異常時の動き**: ファイルが読めない、または形式が不正なら、stderr にメッセージを出して**終了コード 2**。予算は CSV より先に読むので、CSV が壊れていても予算のエラーが先に出ます。

### 月ごとの指定と既定の関係

`Budget.for_month` は `{**default, **months.get(month, {})}` です(`core.py:91-92`)。つまり**カテゴリ単位の上書き**で、月の指定が `default` 全体を置き換えるわけではありません。

- 上の例の 2026-12 は `food: 50000`、`rent: 80000` になります。`rent` は `default` から引き継がれます。
- `months` にない月は `default` だけを使います。
- `default` にも `months` にもないカテゴリは、予算なしとしてチェックされません。
- 予算にあって実績にないカテゴリも、何も出ません。

## 2. どの集計と比べているか

比べる相手は**月別×カテゴリ別の合計**(`monthly_totals(rows)`)です。`--report` で出るのと同じ集計です。既定出力の全期間合計(`total_by_category`)とは比べません。

- **判定**: `実績 > 上限` のときだけ警告します。同額は超過扱いになりません(`test_main_budget_warns` で確認されています)。
- **出力先と形式**: stderr に `警告: 2026-11 food 1,000円超過 (予算 1,000 / 実績 2,000)` の形で出します。月は昇順、同じ月の中は金額の多い順です。
- **終了コード**: 超過があっても 0 のままです。
- **出す時点**: stdout の出力をすべて終えたあとに出します。`--report`、`--format`、`--sort`、`--total` を付けても警告の中身は変わりません。
- **例**: 全期間の food が 2,500 円でも、月ごとに 500 円と 2,000 円に分かれていて上限が 2,000 円なら、警告は出ません。

## 3. ほかのオプションとの組み合わせ

**`--memo`**: **効きます**。メモでの絞り込みは集計の前に行うので(`__init__.py:71-76`)、予算と比べるのは絞り込んだあとの行の月別合計です。ヘルプにもそう書いてあり、`test_memo_budget_uses_filtered_rows` で確認されています。一致する行がなければ集計が空になるので、警告は出ません(「メモに一致する行がありません」の通知だけです)。

**`--category`**: **効きません**。この絞り込みは表示の直前に `totals_by_cat` にかかるだけです(`__init__.py:85-90`)。比較に使う `totals` はその前に作られているので、`--category food` と指定しても rent など**ほかのカテゴリの超過警告も出ます**。表示は food だけなのに警告には全カテゴリが出る、というずれが起きます。ヘルプには書かれておらず、テストもありません。また `--report` と一緒に使うと、`--category` そのものが無視されます。

**`--memo` と `--category` を両方付けた場合**: 比べる相手はメモで絞った行の全カテゴリです。`--category` は予算の比較に関係しません。

### 気になった点(参考)

- **`--category` と警告のずれ**: 上で書いたとおり、仕様なのか見落としなのかがコードからは読み取れません。
