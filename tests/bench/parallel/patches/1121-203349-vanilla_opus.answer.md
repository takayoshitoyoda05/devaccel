`--report` と `--total` を一緒に使うと、月ごとの小計行と最後の総合計行が出るようになりました。テストは既存分と新規6件を合わせて62件すべて通っていて、ruff と pyright もエラーなしです。コミットは `50991a3` です。

```
$ uv run kakeibo data/sample.csv --report --total
2026-11	rent	80000
2026-11	food	2000
2026-11	SUBTOTAL	82000
TOTAL		82000
```

出力の形式は、こちらで次のように決めました。

- **小計行:** 各月の最後に `YYYY-MM<TAB>SUBTOTAL<TAB>月合計` を出します。
- **総合計行:** 最後に `TOTAL<TAB><TAB>総合計` を出します。今までの `--report` と同じく、どの行も3列で、金額にカンマは付けていません。
- **0件のとき:** 1行もなければ `TOTAL<TAB><TAB>0` だけを出します。通常の表示で `--total` を付けたときと同じ扱いです。
- **他のオプションとの組み合わせ:** `--memo` を付けると、絞り込んだ後の金額で小計を出します。`--category` は今まで通り `--report` では効きません。

1点だけ注意があります。カテゴリ名が `SUBTOTAL` だと、小計行と見分けがつきません。普通は使わない名前なので、対策はしていません。

変更したのは `src/kakeibo/__init__.py`（処理と `--help` の説明）と README で、テストは `tests/test_report_total.py` に新しく作りました。README にあった「`--report` と併用しても合計行は出ない」という説明も書き直しています。
