`--budget` の警告に予算比(%)が付き、予算の 90% 以上を使っていれば超過していなくても「注意」が出るようになりました。コミットは `9123b03` です。テスト 61 件はすべて通り、ruff と pyright もエラーなしです。

**出力例(stderr)**
```
警告: 2026-11 food 1,000円超過 (予算 1,000 / 実績 2,000 / 200%)
注意: 2026-11 food 残り 200円 (予算 2,200 / 実績 2,000 / 90%)
```

**こちらで決めた仕様**
- **割合は小数点以下切り捨て**: こうしておくと、超過していない行が「100%」と表示されることはありません。
- **90% の判定は整数で計算**: `実績×10 >= 予算×9` で判定しているので、浮動小数点の誤差で境界がずれることはありません。
- **予算 0 のカテゴリ**: 0 で割れないので割合は出しません。実績が 0 より大きいときは「警告」、0 のときは何も出しません。

**これまでと出力が変わる点**
- 実績がちょうど予算と同じとき、これまでは何も出ませんでしたが、今は「注意 … 残り 0円 / 100%」が出ます。ご要望の「90% 以上」に含まれるためです。既存テストの `test_main_budget_warns` もこれに合わせて書き換えました。
- 超過の警告の末尾に ` / NNN%` が付くので、警告の文字列を読み取っているスクリプトがあれば影響を受けます。
