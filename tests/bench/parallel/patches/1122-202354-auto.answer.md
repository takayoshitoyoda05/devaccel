`click.Path` に `extensions` 引数を足しました。PR は https://github.com/takayoshitoyoda05/devaccel-large/pull/82 です。「証拠を作成中」と出ており、base の `check.sh full` が終わると下書きが解除されます。

- **動き**: `click.Path(extensions=(".csv", ".tsv"))` は `a.CSV` や `a.Tsv` を通し、`a.txt` は `BadParameter` で弾きます。弾くとき、メッセージに許可する拡張子の一覧(`.csv, .tsv`)が出ます。
- **扱いの決め**:
  - 先頭のドットは省略できます(`"csv"`)。
  - 複数部分の拡張子(`.tar.gz`)も指定できます。
  - 存在しないファイルも名前で検査します。ただし `exists=True` で存在しなければ、従来どおり "does not exist" が出ます。
  - ディレクトリと、`allow_dash` で許した `-` は検査しません。
  - `.csv` だけの名前は語幹がないので弾きます。
  - 単独の文字列、空のシーケンス、空の要素は `TypeError` / `ValueError` です。
