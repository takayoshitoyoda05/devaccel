kakeibo の CSV の金額欄(amount)で、表記ゆれを受け付けるようにして。同時に、今たまたま通ってしまっている不正な表記はエラーにして。

金額欄は、前後の半角スペースを取り除いたあと、次の形のときだけ有効とする。

    [-][¥ または ￥]数字部[円]

- 数字部は次のどちらか。数字は ASCII の `0`〜`9` だけ。
  - 数字だけの1桁以上の並び(例: `800`、`007` は 7)
  - 3桁区切り: 1〜3桁の数字のあとに「`,` + 数字ちょうど3桁」が1回以上続く形(例: `1,200`、`1,234,567`)
- `-`(負数。返金など)、通貨記号(半角 `¥` か全角 `￥` のどちらか1つ)、末尾の `円`(1つ)はそれぞれ省略可。順序はこの通りに固定(`-¥500` は有効、`¥-500` は不正)。
- 有効な例: `1200` / ` 800 ` / `"1,200"` / `"¥80,000"` / `"￥1,234,567円"` / `800円` / `-500` / `-¥500`
- 上の形に合わないものはすべて不正。例: `"12,00"`・`"1,2000"`・`",100"`・`"1,200,"`・`"1,,200"`(区切り位置の誤り)、`+500`、`1_000`、`１２００`(全角数字)、`1.0`、`¥¥500`、`500円円`、`¥ 500`・`- 500`・`1 200`(途中の空白)、`¥`・`円`・`-`・空文字(数字が無い)。`+500`・`1_000`・全角数字は今は通ってしまうが、不正として扱う。
- 不正な行の扱いは今と同じ: stderr に `行番号: 金額が整数ではありません: '元の値'`(元の値は CSV の欄の値そのままを今と同じ `repr` 形式で)を不正な行すべてについて出し、stdout には何も出さず終了コード 1。
- 出力側は変えない(text は桁区切りあり、`--format csv` と `--report` は桁区切りなしの整数。負数は `-500` のように出る)。
- カンマを含む金額は CSV 上で引用符で囲まれている前提でよい(囲まれていない `1,200` は別の列として読まれる。そこは対応不要)。
