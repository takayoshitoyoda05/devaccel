## 原則
- 変更した振る舞いを、ユーザーと同じ入口から動かして確かめる(テストが通った、では終わらない)。
- 正常系1つと、変更に関係する異常系1つ以上。
- 結果は「何を実行し、何が出て、期待と合っていたか」を短く報告する。確認できなかったことは確認できなかったと書く。

## 起動と確認
<!-- devaccel:fill 例:
- CLI: `uv run <cmd> <サンプル入力>` → 出力を期待値と比較
- API: `uv run <server> &` 起動 → `curl -s localhost:PORT/...` で正常系・異常系 → 停止
- ライブラリ/純粋ロジック: `uv run python -c "..."` で代表入力、性質がある関数は Hypothesis でプロパティ確認
